# Графическое приложение для визуализации функции

Клиентское приложение на Python с использованием PyQt5.

## Описание

Приложение отображает кусочно-заданную функцию.  
Все вычисления выполняются на сервере.  
Клиент получает готовые данные и строит график.

---

## Возможности

- авторизация пользователя
- регистрация пользователя
- настройка параметров функции (a, b, c)
- построение графика
- отображение таблицы значений
- автоматический масштаб

---

## Функция

f(x):

- cos(a * x), если x < -π  
- b / (x + π), если -π ≤ x < 0  
- cot(c + x), если x ≥ 0  

Диапазон:
x ∈ [-10, 10]

---

## Архитектура клиента

Клиент:
- отправляет запросы на сервер
- получает список точек
- отображает данные

Клиент не выполняет вычисления функции.

---

## Протокол

Все команды отправляются через TCP.

### Авторизация

auth&login&password

Ответ:
auth+  
auth-  

---

### Регистрация

reg&login&password&email

Ответ:
reg+  
reg-  

---

### Получение точек

calc&a&b&c&xmin&xmax&step

Ответ:
calc&x1,y1;x2,y2;x3,y3;...

---

## Запуск

Установи зависимости: pip install PyQt5 PyQtChart

Запусти приложение: python widget.py 

---

## Настройка

Адрес сервера задается в коде: TcpClient(host="127.0.0.1", port=1234)
